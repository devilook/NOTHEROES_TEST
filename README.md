# НЕ ГЕРОИ

Пошаговая тактическая игра на карте: до 4 игроков, у каждого 5 юнитов.

## Прототип

Открыть `index.html` в браузере, сборка не нужна.

Партия идёт по правилам из `docs/rules.md` на тестовых юнитах:
1. **Лобби.** Фракция для каждой стартовой зоны.
2. **Очерёдность.** Бросок к6, при ничьей переброс.
3. **Инициатива.** Бросок к30 для каждого юнита и героя, затем выбор места на колесе.
4. **Расстановка.** Юниты встают в стартовые зоны в порядке колеса.
5. **Бой.** Ходы по колесу:
   - движение с подсветкой пути;
   - атака кликом по цели в прицеле;
   - сдвиг по колесу кликом по подсвеченному месту;
   - Enter — конец хода.

Все броски видны в лотке кубиков.

## Структура

| Файл | Что внутри |
|---|---|
| `src/map.js` | карта в ASCII: стены, полустены, места жетонов, зоны. Правится вручную |
| `src/engine.js` | игровая логика без DOM: фазы партии, колесо, движение, бой. Потом пойдёт на сервер |
| `src/ui.js` | отрисовка поля (SVG), панель, ввод |
| `src/wheel.js` | колесо инициативы |
| `src/dice.js` | лоток кубиков с анимацией |
| `docs/` | правила, решения, вопросы, прогресс. Начинать с `CLAUDE.md` |
| `tests/` | тесты логики: `node --test tests/*.test.js` |
