# НЕ ГЕРОИ

Пошаговая тактическая игра на карте: до 4 игроков, у каждого 5 юнитов.

## Прототип механики движения

Открыть `index.html` в браузере, сборка не нужна.

- **Расстановка.** Каждый игрок ставит 5 юнитов в свою угловую зону 3×3.
- **Бой.** Игроки ходят по очереди. Клик по юниту показывает, куда он может дойти: число в углу клетки — сколько шагов до неё. При наведении на клетку виден путь. Клик отправляет юнита. Двигаться можно только ортогонально.
- **Очки хода.** У каждого юнита свой запас. Его можно тратить по частям. «Отменить ход» и Ctrl+Z откатывают перемещение, Enter завершает ход.
- **Правила прототипа.** На панели справа переключается, проходимы ли синие проёмы, клетки с крестиком и свои юниты.

## Структура

| Файл | Что внутри |
|---|---|
| `src/map.js` | карта в ASCII: стены, проёмы, объекты, зоны. Правится вручную |
| `src/engine.js` | игровая логика без DOM: расстановка, поиск пути, ходы. Потом пойдёт на сервер |
| `src/ui.js` | отрисовка поля (SVG) и панель |
| `tests/` | тесты логики: `node --test tests/*.test.js` |
