# НЕ ГЕРОИ

Пошаговая тактическая игра на карте: до 4 игроков, у каждого 5 юнитов.

## Прототип

Открыть `index.html` в браузере, сборка не нужна.

Партия идёт по правилам из `docs/rules.md`:
1. **Лобби.** Отметить зоны, где сидят игроки.
2. **Фракции.** Бросок к6 за порядок выбора или случайная раздача.
3. **Порядок инициативы.** Бросок к6: кто первым бросает к30.
4. **Колесо.** К30 и выбор места для юнитов 1…5, затем героев.
5. **Расстановка.** Юниты встают в стартовые зоны в порядке колеса.
6. **Бой.** Ходы по колесу:
   - движение;
   - атака;
   - способности;
   - сдвиг по колесу.

Снизу — ширма игрока. Нечисть — настоящие карты, остальные фракции пока тестовые.

## Структура

| Файл | Что внутри |
|---|---|
| `src/factions.js` | данные фракций: герои, юниты, способности |
| `src/screen.js` | ширма игрока |
| `src/map.js` | карта в ASCII: стены, полустены, места жетонов, зоны. Правится вручную |
| `src/engine.js` | игровая логика без DOM: фазы партии, колесо, движение, бой. Потом пойдёт на сервер |
| `src/ui.js` | отрисовка поля (SVG), панель, ввод |
| `src/wheel.js` | колесо инициативы |
| `src/dice.js` | лоток кубиков с анимацией |
| `docs/` | правила, решения, вопросы, прогресс. Начинать с `CLAUDE.md` |
| `tests/` | тесты логики: `node --test tests/*.test.js` |
